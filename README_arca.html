🦙 Ollama Quota Widget

Ollama Cloud 사용량을 안드로이드 폰에서 실시간으로 모니터링

✍️ 이 소개글은 Hermes Agent + GLM 5.2로 작성되었습니다.

ollama.com이 공식 API 대신 웹 대시보드만 제공해서, 할당량을 확인하려면 매번 사이트에 들어가야 했죠. 이 앱은 그걸 폰에서 한눈에 보게 해줍니다 — 홈화면 위젯, 상단 고정 알림, 모델별 사용량 분석까지.

📖 사용 방법

1설치

  1. 아래 링크에서 APK 파일을 다운로드합니다
  2. 폰의 파일 탐색기 앱으로 APK 파일을 실행합니다
  3. "출처를 알 수 없는 앱" 경고가 나오면 설정에서 허용 후 설치합니다

2계정 추가 및 로그인

  1. 앱을 실행하고 "+ 새 계정 추가" 버튼을 누릅니다
  2. 추가된 계정 카드에서 "로그인" 버튼을 누릅니다
  3. 앱 내 웹창이 열리면 Ollama 계정으로 로그인합니다
  4. 로그인이 완료되면 자동으로 쿠키가 저장되고 웹창이 닫힙니다

3상단 알림 켜기

  1. 화면 하단의 "상단 알림 켜기" 버튼을 누릅니다
  2. 알림 권한 요청이 나오면 허용합니다
  3. 상단 알림바에 Ollama Quota가 고정됩니다
  4. 알림을 펼치면(아래로 드래그) 계정별 상세 사용량이 보입니다

4홈화면 위젯 추가

  1. 홈화면 빈 공간을 길게 누릅니다
  2. "위젯" 메뉴 진입
  3. "Ollama Quota" 위젯을 홈화면에 드래그합니다
  4. 위젯의 새로고침 버튼(↻)을 누르면 즉시 갱신됩니다

5모델별 사용량 확인

  1. 알림을 펼치거나 앱을 열면 각 계정 아래에 모델별 정보가 표시됩니다
  2. 앱의 계정 카드에서 체크박스 3개로 표시 항목을 on/off 합니다:
    • ☑ 모델별 usage % 표시
    • ☑ 모델별 request 수 표시
    • ☑ 모델별 usage/requests 비율 표시
  3. "전체 설정 저장" 버튼을 눌러 적용합니다

6알림 규칙 설정

  1. 계정 카드의 "할당량 경고 설정"에서 "+ 알림 규칙 추가"를 누릅니다
  2. 세션/주간 선택, 임계값(%) 입력, 활성화 토글
  3. "전체 설정 저장"으로 저장
  4. 임계값 도달 시 알림이 옵니다

7갱신 주기 변경

  1. 메인 화면의 "자동 갱신 주기 설정"에서 시간/분/초 입력
  2. "적용" 버튼 누름
  3. 기본값은 30분, 최소 1초

⚠️ 주의사항

  • ⚠️ Ollama Cloud 계정 필요 — 이 앱은 Ollama Cloud 사용자를 위한 모니터링 도구입니다. 로컬 Ollama와는 무관합니다.
  • ⚠️ WebView 로그인 방식 — 공식 API가 없어 쿠키 기반 스크래핑을 사용합니다. ollama.com 사이트 구조가 변경되면 일시적으로 작동하지 않을 수 있습니다.
  • ⚠️ 로그인 만료 — 세션이 만료되면 "로그인 만료" 알림이 옵니다. 계정 카드에서 다시 로그인 버튼을 눌러주세요.
  • ⚠️ 쿠키 암호화 저장 — 로그인 정보는 안드로이드 암호화 저장소(EncryptedSharedPreferences)에 저장되어 평문으로 노출되지 않습니다.
  • ⚠️ 갱신 주기 — 너무 짧게 설정하면 배터리 소모가 크고 ollama.com 서버에 부담을 줍니다. 15분~30분을 권장합니다.
  • ⚠️ 알림 확장 뷰 제한 — 안드로이드 시스템 제한(252dp)으로 알림 확장 시 모델이 많으면 usage 기준 상위 2개만 표시됩니다. 전체 모델 목록은 앱에서 확인하세요.
  • ⚠️ 한줄 알림 최대 2개 — 상단 알림 접힌 상태에서는 2개 계정까지만 표시됩니다 (안드로이드 제한).
  • ⚠️ 부팅 시 자동 시작 — "핸드폰 재부팅 시 자동 시작" 스위치를 켜면 폰 재부팅 후 자동으로 알림이 시작됩니다.
  • ⚠️ 출처 불명 경고 — Play Store가 아닌 APK 직접 설치이므로 설치 시 경고가 나옵니다. 정상적인 앱이니 허용하시면 됩니다.
  • ⚠️ Android 8.0 이상 필요 — Android 8.0 (Oreo) 이상에서만 작동합니다.

🛡️ 설치 전 보안 검증 안내

⚠️ 타인이 만든 APK 파일을 설치하기 전에 반드시 확인하세요

최근 커뮤니티에서 누군가 앱을 만들어 공유하면서 APK 파일 내부에 악성코드를 심어놓은 사례가 있었습니다. 겉보기엔 정상적인 앱처럼 동작하지만, 백그라운드에서 개인정보를 탈취하거나 광고를 띄우는 코드가 숨겨져 있을 수 있습니다. 아무리 신뢰할 수 있는 출처라도, APK 파일을 설치하기 전에는 반드시 아래 검증 과정을 거치는 것을 권장합니다.

📋 설치 전 확인해야 할 것

  • ✅ 소스코드 확인 — 개발자가 GitHub 등에 소스코드를 공개했는지 확인하세요. 소스코드가 공개되어 있다면, 다른 사람이 이미 검토한 코드입니다. 이 앱의 소스코드는 GitHub에서 누구나 열람 가능합니다.
  • ✅ AI 보안 검사 — APK 파일을 VirusTotal에 업로드해서 70개 이상의 백신 엔진으로 검사받으세요. 악성코드가 감지되면 절대 설치하지 마세요.
  • ✅ 백신 앱으로 검사 — 폰에 설치된 백신 앱(Play Protect, McAfee, Kaspersky 등)으로 다운로드한 APK 파일을 스캔하세요.
  • ✅ 권한 확인 — 설치 시 요청하는 권한이 앱 기능에 맞는지 확인하세요. 이 앱이 요청하는 권한은: 인터넷, 알림, 포그라운드 서비스, 부팅 완료 — 이 4개뿐입니다. 연락처 접근, SMS, 위치 정보 등 불필요한 권한을 요구하면 의심해야 합니다.
  • ✅ APK 디컴파일 — 기술적 지식이 있다면 jadx 같은 도구로 APK를 디컴파일해서 내부 코드를 직접 확인할 수 있습니다. 악성코드는 보통 난독화되어 있으므로, 난독화 여부도 참고하세요.
  • ✅ 커뮤니티 피드백 — 다른 사용자들의 댓글과 피드백을 확인하세요. "이상한 알림이 떠요", "배터리가 갑자기 빨리 닳아요" 같은 제보가 있으면 주의해야 합니다.

🔍 이 앱의 보안 조치

  • ✅ 소스코드 100% 공개 — GitHub에서 모든 코드를 열람하고 검토할 수 있습니다
  • ✅ 쿠키 암호화 저장 — 로그인 정보(쿠키)를 Android Keystore 기반 암호화 저장소에 보관합니다
  • ✅ 최소 권한 원칙 — 앱 기능에 필요한 4개 권한만 요청합니다
  • ✅ WebView 화이트리스트 — 로그인 웹창은 ollama.com, Google, GitHub만 허용합니다
  • ✅ 백업 차단 — ADB 백업으로 앱 데이터가 추출되지 않도록 차단되어 있습니다

💡 요약: 아무리 좋아 보이는 앱이라도, 소스코드가 공개되어 있고 백신 검사를 통과한 앱만 설치하세요. 한 번 감염되면 개인정보, 계정, 금융 정보까지 노출될 수 있습니다.

📝 후기

이 어플은 안티그래비티로 만든 내 첫 바이브 코딩 결과물이었음.

아쉬운 점은 모델별 사용량이 보이지 않는 점이었는데, Gemini 3.1 Pro가 "방법이 없다, 절대 불가능하다"고 해서 그냥저냥 만족하고 썼다가, 이번 주 Ollama 투배럭을 거의 못 써서 할당량 녹일 겸 "헤르메스로 GLM 5.2를 이용해서 다시 시도해볼까?"라는 생각으로 시작한 두 번째 바이브코딩임.

근데 시발 안티그래비티에서 Gemini 3.1 Pro로 4시간 동안 씨름했다가 포기한 모델별 사용량 기능을 GLM 5.2는 바로 만들어주더라 ㅋㅋ

바이브 코딩에 문외한에다가 내가 알기론 헤르메스가 전용 코딩 프로그램은 아닌 걸로 알고 있어서 어플의 완성도가 미숙할 수도 있음.

항상 챗붕이들에게 받기만 해서 이번엔 나도 뭔가를 줘보고자 올림.
